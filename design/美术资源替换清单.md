# 美术资源替换清单

更新：2026-11-09。现阶段以统一、可识别、能传达功能为准；用户后续再选择完整美术风格。

## 共同约束

- 预览：深蓝底、青色细线；金色表示选中或放置预览，红色表示冲突和不可达。
- 成品：同一布局与构件，转为灰绿地面、木色家具、低饱和材质的桌面模型。不能为每张卡换一张与实际布局无关的成品建筑图。
- 平面家具朝向与四个 90°方向一致。卡牌升级只改性能，素材尺寸不能随星级改变。
- 优先透明背景 SVG；插画可用透明 PNG/WebP。线条、选中边框、冲突颜色留给程序叠加，不烘焙进图片。
- 一张卡代表一种蓝图，拖入后可重复实例化。图标和家具无需为每个实例单独制作。

## 暂时不需要准备

自由旋转相机、多视角整栋建筑图片、复杂屋顶、角色动画、大场景环境、每个星级的不同尺寸模型。未来若改为真实三维场景，再单独确定 GLB 等模型规格；本轮无需提前生产。

## 建议替换顺序

先定一套 **办公单元 + 结构柱 + 保温窗**，同时检查卡面、平面、立面和实体轴测中的一致性。确认后再扩展至另外三种功能和其余结构/窗型。先给这三个样本即可开始换风格，不必一次准备齐全部资源。
