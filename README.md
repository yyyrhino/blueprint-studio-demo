# 构想事务所 · 蓝图评审 Demo

以建筑布局与简化 BPS 取舍为主题的网页版卡牌原型。玩家购买蓝图、选择本轮装备，再在固定网格上组织空间，通过结构、功能、环境三轮评审。

**在线试玩：[打开构想事务所](https://yyyrhino.github.io/blueprint-studio-demo/)**

推荐使用电脑浏览器。无需下载；刷新页面会重新开局，当前没有存档。

## 如何游玩

1. 在「评审进程」查看本轮主题与条件，进入「灵感商店」领取、购买或进修蓝图。买卖同价，刷新商店消耗金币。
2. 在「蓝图装备」选择本轮能修改的内容；三轮分别开放 3、4、5 个槽位。拥有一张蓝图即可重复部署，不消耗部署次数。
3. 在「方案搭建」点击蓝图后点击空位，或直接拖入平面。右键、R 或旋转按钮可旋转 90°；选中已放模块后可旋转或移除。
4. 结构和窗与围护通过「应用到整栋方案」设置。右上角切换平面、南立面或固定轴测；回到平面编辑。
5. 布置通路连接南侧入口，使功能模块至少有一侧可达。空地本身不算通路，未接通模块不贡献设计费。
6. 提交评审后逐模块计算设计费。通过后领取金币、进入商店并推进下一轮；失败扣信誉，累计三次失败结束本局。
7. 完成三轮后，蓝图转为桌面模型，可导出当前方案的固定视角 SVG 图。

装备和搭建界面可以来回切换。卸下蓝图会撤回该蓝图本轮尚未通过评审的修改，已通过评审的方案会保留。

## 三轮目标

| 轮次 | 主题 | 设计费门槛 | 主要要求 |
|---|---|---:|---|
| 1 | 结构提案 | 1,550 | 已选结构，功能空间均可达 |
| 2 | 功能组织 | 2,100 | 至少 8 个办公、1 个会议、1 个休息，并保持可达 |
| 3 | 环境整合 | 3,000 | 保留功能要求，采用保温或遮阳围护 |

设计费用于通关，金币用于本局买牌、进修和刷新；两个系统独立。13 种蓝图包括结构、功能、通路和围护。网格固定为 6×6 轴网，通路采用半格精度。

## 本地开发

需要 Node.js 与 npm。本次构建和规则测试使用 Node.js 24.22.1。

```sh
npm install
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5175/`。

```sh
npm test
npm run build
npm run preview
```

源码在 `src/`，规则测试在 `tests/`。`npm run build` 生成 `docs/` 中的静态网页，并自动生成 `.nojekyll`。构建使用相对资源路径，适用于 GitHub Pages 的项目子目录。

## GitHub Pages 发布

仓库 Settings → Pages → Deploy from a branch，选择 `main` 分支和 `/docs`。修改源码后运行构建，把源码及更新后的 `docs/` 一同提交。网页运行不依赖开发电脑保持开机。

## 文件与美术

- `src/game.js`：布局、经济、蓝图与计分规则。
- `src/App.jsx`：四个主要界面及回合流程。
- `src/Plan.jsx`、`src/BuildingViews.jsx`：平面、立面、轴测与成品模型。
- `src/Cards.jsx`、`src/styles.css`：卡面和界面样式。
- [美术资源替换清单](design/美术资源替换清单.md)：后续素材替换规格。
- `third-party/`：网页所含 React、React DOM、Scheduler 的许可证文本。

当前视觉采用程序化 SVG，未使用第三方 Balatro 项目的代码、美术、字体或音频。

## 原型范围

这是玩法和数值验证用 Demo。光热效果为游戏规则抽象，并非真实 BPS 求解或建筑合规工具。轴测是固定投影绘制，不支持自由旋转或三维网格导出。暂不包含存档、局外成长、真实竞标对手、多层、剖面和同名牌合成；数值仍需试玩平衡。
